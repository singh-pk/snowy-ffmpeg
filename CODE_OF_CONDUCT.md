# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good faith, critique code rather than people, and accept that maintainers have the final say on what is acceptable.

## Scope

It applies in every project space (issues, pull requests, discussions, reviews) and whenever you represent the project elsewhere. It applies equally to text written with the help of AI tools.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@singh-pk](https://github.com/singh-pk), through GitHub. Reports are handled confidentially, and the enforcement guidelines of the Contributor Covenant decide the response.
